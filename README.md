# 🎯 Tic Tac Toe Game (Python Console Version)

This is a simple implementation of the classic **Tic Tac Toe** game using **Python**, played entirely in the **command line (console)**. It supports two players who take turns placing their mark (X or O) on a 3x3 grid.

## 🧠 Game Logic

- The game board is represented using a 2D list or a flat list of 9 elements.
- Players take turns choosing a position on the board by entering a number.
- The program checks after each move for a **win** or a **draw**.
- If a player wins or the game ends in a draw, the result is displayed and the game ends.

## 🚀 Features

- Fully interactive command-line interface
- Two-player mode
- Input validation to prevent invalid or occupied moves
- Win and draw detection

## 🛠️ Technologies Used

- **Python 3**
- Basic standard libraries (no external dependencies)

## ▶️ How to Run
